1 · Idea 0001 · Build & compatibility

build & compatibility · 2026-08-31

Lower the published Java floor from 21 to 17

All three jars run inside the consumer's own processes, so <release> decides who can adopt SpecBinder at all. The dependency and language audits both come back clear — every dependency is Java 8 bytecode, nothing in the source is newer than Java 16 — leaving a single List.getFirst() in the way.
